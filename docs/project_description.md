# Проект: Expert System for Computer Diagnostics

## Цель проекта

Создать экспертную систему, способную диагностировать типичные неисправности компьютера на основе симптомов пользователя.

## Архитектура

1. База знаний
   - факты: наблюдаемые признаки
   - правила: IF ... THEN ...
   - концепты: основные сущности предметной области

2. Семантическая сеть
   - связи между компонентами компьютера
   - задания зависимостей и причинности

3. Логический вывод
   - прямой вывод на основе правил
   - генерация списка диагностических шагов

4. Вероятностный модуль
   - оценка уверенности системы
   - пример простого взвешивания признаков

## Пример диагностического сценария

Если пользователь сообщает:

- монитор включен
- нет изображения
- компьютер включается

то система предлагает проверить видеокабель, разъемы видеокарты и подключение монитора.

## Используемые технологии

- Python 3
- стандартная библиотека
- JSON для хранения знаний
- простые классы и структуры данных
