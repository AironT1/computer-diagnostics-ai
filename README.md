# Computer Diagnostics Expert System

Этот проект представляет собой стартовый шаблон экспертной системы для диагностики неисправностей компьютера. В рамках проекта реализованы:

- база знаний
- логические правила
- логический вывод
- семантическая сеть
- простой вероятностный модуль
- пример диагностики типичных проблем ПК
- документация и структура для дальнейшего развития

## Предметная область

Система помогает диагностировать типичные проблемы компьютера:

- ПК не включается
- нет изображения на мониторе
- зависает после запуска
- перегрев
- проблемы с интернетом
- шумы/вибрации
- отсутствие звука
- медленная работа

## Основные компоненты

- `app/knowledge_base.py` — база знаний
- `app/rules.py` — представление правил
- `app/inference_engine.py` — механизм логического вывода
- `app/semantic_network.py` — семантическая сеть
- `app/probabilistic_module.py` — вероятностная оценка
- `app/expert_system.py` — главный класс экспертной системы
- `main.py` — демонстрационный запуск
- `data/*.json` — факты, правила, понятия
- `docs/` — документация

## Пример использования

```python
from app.expert_system import ExpertSystem

system = ExpertSystem()

system.add_rule({"no_image": True, "monitor_on": True}, {"check": "video_cable"})
system.add_rule({"power_on": False}, {"check": "power_supply"})

result = system.diagnose({
    "no_image": True,
    "monitor_on": True,
    "power_on": True,
})

print(result)
```
