# Архитектура системы

Проект состоит из следующих блоков:

- `app/knowledge_base.py` — хранение фактов и правил
- `app/rules.py` — правила продукционного типа
- `app/inference_engine.py` — механизм логического вывода
- `app/semantic_network.py` — представление семантической сети
- `app/probabilistic_module.py` — оценка вероятности
- `app/expert_system.py` — объединение компонентов
- `main.py` — запуск демонстрационного сценария

## Логика работы

1. Пользователь вводит симптомы.
2. Система сравнивает их с правилами.
3. Выполняется прямой вывод.
4. Генерируется список действий для диагностики.
5. Система оценивает уверенность в выводе.
